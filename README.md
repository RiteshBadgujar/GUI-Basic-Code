# 🖥️ GUI Basic Code

A collection of Java Swing GUI programs demonstrating the fundamentals of Graphical User Interface (GUI) development. This repository includes examples of layouts, event handling, forms, panels, dashboards, menus, and basic desktop applications.

## 📚 Topics Covered

- JFrame
- JPanel
- JButton
- JLabel
- JTextField
- BorderLayout
- FlowLayout
- GridLayout
- Event Handling
- Action Listener
- Key Events
- Login Form
- Login Validation
- Dashboard UI
- Menu Bar
- Student Form
- Calculator UI
- Multiple Panels
- Dynamic Dashboard
- Swing Components

## 🛠 Technologies Used

- Java
- Java Swing
- AWT
- Eclipse IDE
- JDK 8+

## ▶️ How to Run

1. Clone the repository.
2. Open the project in Eclipse or IntelliJ IDEA.
3. Compile and run any Java file to explore the GUI example.

## 🎯 Learning Objectives

- Learn Java Swing fundamentals.
- Build desktop GUI applications.
- Understand layout managers.
- Handle user events.
- Create login forms and dashboards.
- Design interactive user interfaces.
